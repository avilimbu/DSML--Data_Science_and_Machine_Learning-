# Day 26 – NumPy Basics

## NumPy

**NumPy (Numerical Python)** is a Python library used for efficient numerical and scientific computing. It provides a powerful data structure called an **ndarray (NumPy array)**, which is faster and more memory-efficient than standard Python lists when working with large amounts of numerical data.

### Key Features

* N-dimensional arrays (`ndarray`)
* Fast mathematical operations
* Linear algebra functions
* Statistical functions
* Random number generation

## NumPy Arrays

A NumPy array is a collection of elements of the same data type stored in a multidimensional structure.

Important concepts:

* **Rank** – Number of dimensions in an array
* **Shape** – Size of an array along each dimension
* **Indexing** – Accessing elements using square brackets `[]`
* Arrays can commonly be created from Python lists.

### `np.zeros()` and `np.ones()`

These functions create arrays filled with zeros or ones.

They are useful for:

* Efficient memory allocation
* Creating placeholders
* Machine learning initialization
* Boolean masks
* Matrix operations

They are commonly used for initializing weights, biases, and other model parameters in machine learning.
